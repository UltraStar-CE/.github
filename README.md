# USCE community profile

We publish the [UltraStar Community Edition organization profile](https://github.com/UltraStar-CE)
from this repository. The karaoke game and our shared community policies live
in [USCE](https://github.com/UltraStar-CE/USCE).

The profile artwork uses the USCE star and microphone identity. Its source and
generation provenance are recorded in the game's
[branding directory](https://github.com/UltraStar-CE/USCE/tree/HEAD/branding).
